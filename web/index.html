Kubernetes pods

Resonate reads pods through your GitLab agent: no cluster credentials needed. The agent's config must grant this project user_access, and GITLAB_TOKEN needs the k8s_proxy scope. A stopped GitLab environment also counts as down.

GitLab sign-in

Create an application on your GitLab (Admin → Applications, or the group's Settings → Applications) with scope api and this redirect URI. Once both fields are set, only GitLab sign-in works.
